# Zentube

Zentube is a local-first desktop media library and playlist manager. The MVP focuses on importing local media, storing metadata in SQLite, creating playlists, playing files offline, and tracking queue history.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run dist
```

## MVP Boundary

The first version does not ship with YouTube downloading. External providers can be added later behind explicit user configuration and clear rights/platform-policy notices.
